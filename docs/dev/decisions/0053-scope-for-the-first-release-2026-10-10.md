# Scope for the first release (2026-10-10)

- Scope: direct voice/video calls and multi-hop live streams (viewers relay automatically). Private-call relaying is DEBUG/test-only today; user-facing background call relaying (a "Helping a call nearby" notification, the person's own activity pre-empts it, pauses below 20% battery) plus multi-hop discovery (naming phase 2) is the first feature after release, behind an experimental switch.
- Publication: the public repositories are MeshLive/meshlive-android, MeshLive/meshlive-ios and MeshLive/.github, all GPL-3.0-or-later, copyright "The MeshLive Authors", each starting from a fresh single commit. The video stress generator is published inside meshlive-android. Device identifiers are scrubbed from published files, and the test phones' app identities are reset after launch. The README named the AI used in a "How this was built" section until 2026-10-21, when that section was dropped, and [CONTRIBUTING.md](../../../CONTRIBUTING.md) sets the policy for AI-assisted work. The speech test audio (LibriSpeech CC BY 4.0, LibriVox public domain, an Open Goldberg Variations CC0 clip) is published with attribution in [THIRD_PARTY_NOTICES.md](../../../THIRD_PARTY_NOTICES.md).
